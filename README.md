# 小小屠龙 · 冰雪复古 官方网站

传奇手游《小小屠龙 · 冰雪复古》官方网站，纯静态站（无后端）。

- 线上地址：<https://xxtl.fmbly.com>
- 首区开服：2026 年 10 月 20 日 14:00
- 支持平台：安卓 / iOS / PC 模拟器，三端数据互通

## 页面结构

| 页面 | 说明 |
| --- | --- |
| `index.html` | 首页：主视觉、特色、单职业、实机截图、公告、活动 |
| `download.html` | 下载：三端下载卡、开服时间表、配置要求、常见问题 |
| `classes.html` | 职业：单职业定位、属性与核心技能 |
| `news.html` / `news-detail.html` | 公告列表 / 公告详情 |
| `activity.html` | 活动专区 |
| `gift.html` | 礼包码兑换与关注福利 |
| `game.html` | 游戏介绍 + 24 张玩法图鉴 |
| `legal.html` | 用户协议 / 隐私政策 / 未成年人保护 / 防沉迷 |

## 技术说明

- 数据集中在 `mock.js`（`DB` 对象），页面只读数据，不散落硬编码
- `api.js` 为 API 桩层，全部返回 mock，接入真实后端时只需替换函数体
- 素材在 `assets/`：主视觉、职业立绘、4 张活动图、24 张玩法图鉴、logo 与二维码
